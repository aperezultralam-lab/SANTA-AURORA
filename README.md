# SANTA AURORA: AFTERLIGHT

Prototipo 3D original de supervivencia narrativa, acción, sigilo y exploración diseñado para PC y móviles.

## Stack
- Three.js / WebGL
- JavaScript ES Modules
- PWA estática
- Render CDN

## Principios
- IP 100% original.
- Misma experiencia jugable en PC y móvil.
- Cámara tercera persona sobre el hombro.
- Combate, sigilo, inventario, crafting, IA, criatura original, misión y narrativa ambiental.
- Resolución dinámica y presets de calidad.
- Una sola tecnología de render para personajes, caras y escenario: Three.js/WebGL. No se usa un motor externo separado para rostros.

## Vertical slice
La primera misión lleva al jugador desde la Avenida Sur de Santa Aurora hasta una estación inundada, un refugio improvisado y la salida norte, con recursos limitados, enemigos humanos, una criatura original y documentos ambientales.

## Ejecutar
Sirve la carpeta `public/` con cualquier servidor HTTP local.
